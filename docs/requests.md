# Feature requests

Every feature request from a client or prospect goes here, verbatim where
possible. The Phase 1 gate is **three paying clients needing the same core
module** — this file is the evidence for that call, so the value is in
recording requests as they come rather than filtering them first.

Record who asked, what they asked for, and what it was blocking. Resist
rewriting a request into a solution; the raw ask is the signal.

Interview questions and outreach tracking live in [`discovery.md`](./discovery.md).
